# Diff Sanitization Implementation Plan

This blueprint details the implementation of the `DiffSanitizer` logic. This 
ensures that Unified Diffs generated by agents are programmatically repaired 
(fixing missing context spaces and incorrect header counts) before being saved 
to disk.

## 1. Goal
To eliminate "malformed patch" errors caused by LLM hallucinations (e.g., 
missing leading spaces, bad arithmetic) by implementing a two-stage repair 
pipeline: **Heuristic Text Repair** followed by **Object-Model Recalculation**.

## 2. Dependencies
*   **Target:** `pyproject.toml`
*   **Action:** Add `unidiff>=0.7.0`.

## 3. Module Specification: `src/vybz/diff_utils.py`

### 3.1 Class `DiffSanitizer`
A stateless utility class for processing raw diff strings.

#### Method: `sanitize(raw_diff: str) -> str`
The main entry point.
1.  Calls `_repair_context_spacing(raw_diff)`.
2.  Calls `_recalculate_headers(repaired_diff)`.
3.  Returns the final clean string.
4.  **Error Handling:** If parsing fails even after repair, it logs a warning 
and returns the `raw_diff` (Fail Open) to ensure the user at least gets the 
content.

#### Method: `_repair_context_spacing(text: str) -> str`
*   **Purpose:** Fix lines that *look* like context but lack the leading space 
    required by the `patch` utility.
*   **Logic:**
    1.  Split text into lines.
    2.  Iterate line by line.
    3.  **State Tracking:** Are we inside a hunk? (Detected by `@@ ... @@`).
    4.  **Heuristic:**
        *   If inside a hunk:
        *   Check if line starts with `+`, `-`, or ` ` (valid).
        *   Check if line is `\` (No newline marker).
        *   If NONE of the above, and the line is not empty: **Prepend a space.**
    5.  Join lines and return.

#### Method: `_recalculate_headers(text: str) -> str`
*   **Purpose:** Fix incorrect line counts (e.g., `@@ -10,3 +10,3 @@`) using `unidiff`.
*   **Logic:**
    1.  Parse text using `unidiff.PatchSet(text.splitlines())`.
    2.  The library automatically recalculates hunk metadata upon parsing.
    3.  Return `str(patch_set)`.
    4.  **Note:** Ensure the output ends with a newline.

### 3. Senior Dev Peer Review

*   **Architecture:** Placing the logic in `diff_utils.py` is clean and adheres
    to the Single Responsibility Principle. `artifact.py` remains focused on 
    routing.
*   **Safety:** The "Fail Open" strategy (returning raw text if sanitization 
    fails) is critical. We never want to discard the agent's output just 
    because our sanitizer got confused.
*   **Performance:** `unidiff` parsing is fast enough for the size of patches 
    we generate.
*   **Edge Case:** The regex heuristic for "Missing Space" is aggressive. It 
    assumes anything inside a hunk that isn't `+` or `-` is context. This is 
    generally true for Unified Diffs but could theoretically mangle a line that
    *looks* like a diff header if the LLM hallucinates nested diffs. However, 
    given the context, this risk is acceptable.

### 4. Verification Script

This script simulates the `DiffSanitizer` logic to prove the concept before 
implementation.

```python
if __name__ == "__main__":
    # Simulation of the heuristic logic
    raw_bad_diff = """--- a/file.py
+++ b/file.py
@@ -1,3 +1,3 @@
 def foo():
-    print("old")
+    print("new")
     return True"""

    print("--- RAW ---")
    print(raw_bad_diff)
    
    lines = raw_bad_diff.splitlines()
    fixed_lines = []
    in_hunk = False
    
    for line in lines:
        if line.startswith("@@"):
            in_hunk = True
            fixed_lines.append(line)
            continue
            
        if in_hunk:
            # Check for valid start chars
            if not line:
                fixed_lines.append(line)
                continue
            
            first_char = line[0]
            if first_char not in ('+', '-', ' ', '\\'):
                # Heuristic: It's a context line missing a space
                fixed_lines.append(" " + line)
            else:
                fixed_lines.append(line)
        else:
            fixed_lines.append(line)
            
    print("\n--- REPAIRED ---")
    print("\n".join(fixed_lines))
