--- COMMANDS ---
 /agent \[name]  : Switch active agent (or list available).
 /clear         : Clear the terminal screen.
 /exit, /quit   : End the session.
 /help          : Show this menu.
 /load <file>   : Load a file into context.
 /save          : Auto-save the last generated artifact.
 /set <mode>    : Set input mode (vi | emacs).
 /theme <name>  : Set UI color theme.
 /update        : Refresh CodeBase snapshot and System Date.

--- KEYBINDINGS ---
 Alt+Enter     : Submit input.
 Enter         : Insert newline.
