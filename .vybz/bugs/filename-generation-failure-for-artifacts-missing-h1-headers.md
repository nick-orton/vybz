# Filename Generation Failure for Artifacts Missing H1 Headers

## 1. Symptom
When saving a Bug Report generated by the QA Lead agent using `/save`, the 
resulting file is named generically (e.g., `artifact-123456.md`) instead of 
deriving a meaningful name from the content (e.g., `login-ui-crash.md`). This 
behavior contrasts with Designs and Intents, which correctly auto-generate filenames.

## 2. Root Cause Analysis
The issue lies in the **brittleness of the filename extraction logic** within 
`src/vybz/artifact.py` combined with **loose output formatting constraints** in
the QA Agent's prompt.

1.  **Code Flaw (`DocumentHandler.extract`):**
    The `DocumentHandler` strictly relies on a regex that matches *only* Level 
    1 Markdown headers to determine the document title.

    ```python
    # src/vybz/artifact.py:124
    title_match = re.search(r'^#\s+(.+)$', candidate_content, re.MULTILINE)
    ```

    If the content lacks a line starting with exactly `# `, the match fails, 
    triggering the timestamp fallback.

2.  **Agent Behavior:**
    Unlike the PM or Senior Dev agents, whose `task_directive` explicitly 
    mandates an output format starting with `# [Title]`, the 
    QA Agent (`src/vybz/agents/qa.toml`) has a vague directive: 
    *"Produce a single Markdown block containing the Bug Report."*
    Consequently, the QA agent often formats bug reports starting with Level 
    2 headers (`## Symptom`) or simply `**Bug:** Title`, causing the regex in 
    `artifact.py` to miss the title entirely.

## 3. Impact
*   **User Friction:** Users must manually rename bug report files after 
    saving, breaking the "Flow" state.
*   **Organization:** The `.vybz/bugs/` directory becomes cluttered with 
    unidentifiable `artifact-*.md` files.

## 4. Proposed Fix
We should implement a defense-in-depth strategy: make the code more robust 
*and* fix the prompt.

### 4.1 Code Fix: Relaxed Regex
Update `src/vybz/artifact.py` to accept Level 2 headers (`##`) if no Level 1 
header is found.

**Change:**
```python
# src/vybz/artifact.py

# Allow # or ## for title extraction
title_match = re.search(r'^#{1,2}\s+(.+)$', candidate_content, re.MULTILINE)
```

### 4.2 Prompt Fix: Strict Formatting
Update `src/vybz/agents/qa.toml` to explicitly require an H1 Title in the 
output format.

**Change:**
```toml
# src/vybz/agents/qa.toml

task_directive = """
...
**Output Format:**
Produce a single Markdown block containing the Bug Report.
The block MUST start with a Level 1 Markdown Header containing the Bug Title 
(e.g., `# Login Page Crash`).
"""
```

## 5. Verification
1.  Apply the regex change to `src/vybz/artifact.py`.
2.  Create a mock artifact with only `## Title`.
3.  Run the unit tests (or a new test case in `tests/vybz/test_artifact.py`) to 
    verify it extracts `title.md`.
