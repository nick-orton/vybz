# Malformed Diff Patches (Missing Context Space)

## 1. Symptom
When a user attempts to save a diff generated by an agent (e.g., `junior-dev`) 
using the `/save` command, and then applies it via `patch -p1 < file.diff`, 
the operation fails with errors similar to:

```text
patch: **** malformed patch at line 4: context line text
```

Or, the patch is rejected because the context lines are treated as garbage text
rather than valid diff context.

## 2. Root Cause Analysis
The Unified Diff standard requires that lines in a hunk start with a specific character:
*   `+` (Addition)
*   `-` (Deletion)
*   ` ` (Space - Context)

**The Defect:** The `diff-generation` skill 
(`src/vybz/agents/skills/diff-generation.toml`) instructs the agent on the 
structure of headers and hunks, but **fails to explicitly mandate** that 
context lines (lines that haven't changed) must start with a leading space 
character.

Consequently, LLMs often output:
```diff
@@ -10,3 +10,3 @@
 context line <-- Missing leading space
-old
+new
 context line <-- Missing leading space
```
Instead of:
```diff
@@ -10,3 +10,3 @@
  context line
-old
+new
  context line
```

While `markdown-it-py` in `ArtifactProcessor` correctly extracts the content, 
it extracts exactly what the LLM generated. Since the LLM views the leading 
space as "indentation" or "invisible," it frequently omits it unless strictly 
instructed otherwise.

## 3. Proposed Fix
Update `src/vybz/agents/skills/diff-generation.toml` to explicitly include the
"Leading Space" rule in the `knowledge` section and enforce it in the 
`abilities` section.

**Draft Content for TOML:**
```toml
knowledge = [
    # ... existing ...
    """
    #### Context Line Syntax
    *   **Mandatory Leading Space:** Every context line (a line that is not a
        `+` or `-`) MUST start with a single space character.
    *   **Failure Mode:** If this space is missing, the `patch` utility will 
    reject the file as malformed.
    """
]

abilities = [
    # ... existing ...
    "Verifying that every context line in the diff block starts with a literal 
    space character ' '."
]
```

## 4. Verification
1.  Update the skill.
2.  Run `vybz junior-dev` and request a refactor that generates a diff.
3.  Inspect the saved artifact to ensure lines starting with neither `+` nor `-`
    have a leading space (ASCII 32).
4.  Run `patch --dry-run -p1 < output.diff` to confirm validity.
